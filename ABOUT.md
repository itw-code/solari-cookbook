## Why Pinetree

I read the mission: *"Intelligence is no longer the bottleneck. Execution is."*

That's exactly the problem I've been solving in my current role. SawitPRO operates in a domain where data exists but is fragmented across legacy systems, manual workflows, and no-API portals. My job has been to close that gap — building the pipelines, apps, and automation that make the data actually usable.

ColdStart is the same instinct applied to computer-use agents: the model can "understand" a task, but can it *execute* reliably in an environment it's never seen? That's the question Pinetree is asking, and that's the question I built ColdStart to answer.
